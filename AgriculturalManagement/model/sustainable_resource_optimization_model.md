# 持続可能な資源投入最適化モデル：基本構想と数理定式化

## 1. はじめに

農業生産の効率を評価する指標として、従来から単位面積当たりの収量（単収）が広く用いられてきた。しかし、単収は土地という一つの生産要素に対する生産量を示すものであり、労働、エネルギー、肥料、機械設備など、その他の投入資源の利用効率を直接的に評価するものではない。

また、単収の増加が投入資源の増加を伴う場合、生産量が増加していても、資源利用という観点では効率が低下している可能性がある。

さらに、短期的な資源投入の削減によって収量を維持できたとしても、土壌養分や土壌有機物などの自然資本を消耗しているのであれば、その生産体系を長期的に持続可能と評価することはできない。

このような問題を踏まえ、本稿では、農業生産の目的を単なる収量最大化から捉え直し、次の基本理念に基づく数理モデルを提案する。

> **必要な生産量を、持続可能な範囲で、最小限の資源投入によって確保する。**

この考え方を「持続可能な資源投入最適化モデル」と仮称し、その基本構造と数理的な定式化を整理する。

なお、本モデルは既存の標準的な生産性指標をそのまま適用したものではなく、農業生産の資源利用と持続可能性を統合的に評価するための概念的な最適化モデルである。

## 2. 基本理念

### 2.1 生産量の最大化から資源投入の最小化へ

一般的な農業生産では、一定の生産条件のもとで収量を最大化することが目標となる場合がある。これを単純化すると、次のように表現できる。

```math
\max Y
```

ここで、 $Y$ は生産量を表す。

一方、本モデルでは、必要な生産量を確保できるのであれば、それを超える収量の増加を必ずしも目標としない。その代わり、必要生産量を確保するために投入する資源を最小化する。

```math
\min R
```

ただし、次の条件を満たすものとする。

```math
Y \geq Y_{\min}
```

各記号の意味は次のとおりである。

- $R$：投入資源量、または資源負担を表す評価関数
- $Y$：実際の生産量
- $Y_{\min}$：必要最低生産量

この定式化では、生産量は最大化の対象ではなく、満たすべき制約条件となる。

例えば、必要生産量が900 kgである場合、1,000 kgを生産する体系と950 kgを生産する体系を比較するとき、後者の方が少ない資源投入で成立するのであれば、後者を選択する合理性がある。ただし、生産量以外の品質、販売価格、経営利益なども考慮する必要がある。

### 2.2 資源利用の最適化

農業生産には、性質や計測単位の異なる複数の資源が投入される。代表的な資源には次のものがある。

| 資源 | 主な内容 | 計測単位の例 |
|---|---|---|
| 土地 | 農地の利用 | ha・年 |
| 労働 | 人的作業 | 時間 |
| エネルギー | 燃料・電力 | MJ |
| 肥料・資材 | 肥料、農薬、種苗など | kg、数量 |
| 機械・設備 | 農業機械、施設の利用 | 稼働時間、年間資本サービス |
| 水 | 灌漑用水など | m³ |

これらの資源は単位が異なるため、単純に加算することはできない。また、ある資源を削減すると、別の資源の投入が増加する場合もある。

例えば、機械作業を削減することで燃料消費が減少する一方、手作業の労働時間が増加する可能性がある。

したがって、本モデルでは、まず資源ごとの投入量を独立して扱い、それぞれの削減可能性と相互関係を評価する。

### 2.3 持続可能性の確保

資源投入の最小化は、自然資本の消耗によって達成されるべきものではない。

例えば、肥料投入を削減して収量を維持したとしても、土壌中に蓄積された養分を継続的に消耗しているのであれば、長期的な生産能力が低下する可能性がある。

そのため、本モデルでは、自然資本の維持を制約条件として設定する。

### 2.4 経営の成立

資源投入が少なく、自然資本が維持されていても、農業経営として必要な利益を確保できなければ、生産体系の継続は困難となる。

したがって、本モデルでは、必要最低限の経営利益も制約条件として扱う。

## 3. 基本モデルの定式化

### 3.1 投入資源のベクトル表現

投入資源を次のベクトルで表す。

```math
\mathbf{R} = (R_1, R_2, \ldots, R_n)
```

ここで、 $R_i$ は資源 $i$ の投入量を表す。例えば、

```math
\mathbf{R} = (R_L, R_W, R_E, R_M, R_K, R_H)
```

とした場合、それぞれ土地、労働、エネルギー、資材、機械設備、水の投入量を表す。なお、自然資本の状態変化は、通常の投入資源とは区別して扱う。

### 3.2 多目的最適化

本モデルの基本的な目的は、各投入資源を可能な範囲で最小化することである。

```math
\min_{\mathbf{x}} \left(R_1(\mathbf{x}), R_2(\mathbf{x}), \ldots, R_n(\mathbf{x})\right)
```

ここで、 $\mathbf{x}$ は栽培方法、機械利用、施肥方法など、農業経営上の意思決定を表す。

この式は多目的最適化問題である。各資源間にはトレードオフが存在するため、すべての資源投入が同時に最小となる解が存在するとは限らない。

したがって、最適解の評価には、パレート最適性を用いることができる。

パレート最適な生産体系とは、他の資源投入を増加させることなく、少なくとも一つの資源投入をさらに削減することができない体系を意味する。

この方法では、異なる資源を恣意的な重みで統合することなく、生産体系間の資源利用上のトレードオフを比較できる。

## 4. 制約条件の設定

### 4.1 必要生産量の確保

第一の制約条件は、必要な生産量を確保することである。

```math
Y(\mathbf{x}) \geq Y_{\min}
```

$Y_{\min}$ は、経営目的に応じて設定する。例えば、契約出荷量、自家消費量、販売計画などに基づいて設定できる。

複数の作物を生産する場合には、作物ごとに必要生産量を設定することもできる。また、収穫物の品質や販売可能量についても必要に応じて条件を設ける。

### 4.2 経営利益の確保

第二の制約条件は、経営として必要な利益を確保することである。

```math
\Pi(\mathbf{x}) \geq \Pi_{\min}
```

ここで、 $\Pi$ は経営利益、 $\Pi_{\min}$ は必要最低経営利益を表す。

経営利益は、基本的に次のように表せる。

```math
\Pi = V - C
```

- $V$：販売収入などの収益
- $C$：生産・販売に要する費用

実際の評価では、家族労働、自有地、自有機械などの扱いを明確にし、農業所得、会計上の利益、経済的利益を混同しないようにする必要がある。

また、利益と現金収支は異なるため、長期的な経営継続性の評価では資金繰りについても別途検討する。

### 4.3 自然資本の維持

第三の制約条件は、自然資本の維持である。自然資本の状態を $S_t$ とすると、その時間変化を概念的に次のように表せる。

```math
S_{t+1} = S_t + G_t - U_t
```

ここで、 $S_t$ は時点 $t$ の自然資本の状態、 $G_t$ は回復・形成量、 $U_t$ は消耗・流出量を表す。

同じ単位で測定できる状態量について、一定期間にわたる維持を求める場合には、次の条件を設定できる。

```math
S_{t+T} \geq S_t
```

ただし、自然資本は単一の数量ではなく、土壌有機炭素、養分、水資源など、複数の状態指標によって構成される。

そのため、実際には維持すべき指標を個別に設定し、それぞれに適切な下限値、上限値、目標範囲などを与える必要がある。

例えば、土壌pHのように適正範囲が存在する指標については、単純な増加を望ましい変化とはみなさない。また、評価期間末の状態だけでなく、途中の著しい劣化を防ぐ条件も必要となる。

## 5. 持続可能な資源投入最適化モデルの統合形

以上を統合すると、本モデルの基本形は次のようになる。

```math
\begin{aligned}
\text{minimize}_{\mathbf{x}}\quad
& \left(R_1(\mathbf{x}),\ldots,R_n(\mathbf{x})\right) \\
\text{subject to}\quad
& Y(\mathbf{x}) \geq Y_{\min}, \\
& \Pi(\mathbf{x}) \geq \Pi_{\min}, \\
& \mathbf{S}_{t+T}(\mathbf{x}) \succeq \mathbf{S}_t.
\end{aligned}
```

最後の条件は、自然資本の各維持対象指標について適切な維持条件を満たすことを簡略化して表現している。このベクトル不等式は、単純な増加が適切な状態指標を対象とする。適正範囲を持つ指標には個別の範囲制約を設定する。

このモデルの特徴は、生産量、利益、自然資本の維持を制約条件とし、それらを満たす範囲において投入資源の最小化を目指すことである。

### 5.1 複数年での評価

農業生産は気象条件や土壌状態に左右されるため、単年度の評価だけでは生産体系の継続可能性を十分に判断できない。

そこで、評価期間を $T$ 年間とし、資源投入量を次のように表す。

```math
R_i(\mathbf{x}) = \sum_{t=1}^{T} r_{i,t}(\mathbf{x})
```

ここで、 $r_{i,t}$ は年 $t$ における資源 $i$ の投入量である。土地は面積と利用期間、機械設備は期間中に提供されるサービス量など、各資源に適したフロー量を使用する。

生産量と利益についても、各年の必要条件を設定できる。

```math
Y_t(\mathbf{x}) \geq Y_{\min,t}
```

```math
\Pi_t(\mathbf{x}) \geq \Pi_{\min,t}
```

これらを各年に適用する場合、毎年の条件を満たす体系を求めることになる。

一方、年次変動を許容する経営では、複数年の累積生産量や利益、必要な資金準備などを条件にする方が適切な場合もある。

### 5.2 生産の安定性

農業生産には気象変動や病害虫などによる不確実性が存在する。そのため、生産の安定性を考慮する場合には、必要生産量を満たす確率を制約条件として設定できる。

```math
\Pr\left(Y_t \geq Y_{\min,t}\right) \geq 1-\varepsilon
```

ここで、 $\varepsilon$ は必要生産量を確保できない確率の許容上限を表す。ただし、この条件を実際に評価するには、気象条件、収量変動、栽培管理などに関する十分なデータが必要となる。

## 6. 資源投入を単一の評価値で比較する場合

多目的最適化では、複数のパレート最適解が存在する可能性がある。

それらの中から一つの生産体系を選択する必要がある場合、資源投入量を基準値によって無次元化し、重みづけして比較する方法も考えられる。

```math
R_{\mathrm{eval}}(\mathbf{x})
= \sum_{i=1}^{n} w_i\frac{R_i(\mathbf{x})}{R_{i,\mathrm{ref}}}
```

ここで、

- $R_{\mathrm{eval}}$：総合資源負担指数
- $R_i$：資源 $i$ の投入量
- $R_{i,\mathrm{ref}}$：資源 $i$ の正の基準投入量
- $w_i$：資源 $i$ の重み

とする。

重みは、例えば次の条件を満たすように設定する。

```math
w_i \geq 0, \qquad \sum_{i=1}^{n}w_i = 1
```

重みは、資源の経済的価値、希少性、調達上の制約などを踏まえて設定することができる。

ただし、重みの設定によって評価結果が変化する可能性があるため、この指数は補助的な評価方法として扱う。

本モデルでは、単一指数への集約を必須とはせず、資源ごとの投入量とパレート最適性による比較を基本とする。

## 7. 本モデルの特徴と意義

### 7.1 必要以上の増産を目的としない

必要な生産量を確保できるのであれば、それ以上の増産よりも、資源投入の削減を優先する選択が可能となる。ただし、増産による利益の増加が資源投入の削減とどのような関係にあるかについては、経営目的に応じた判断が必要である。

### 7.2 資源間の代替関係を評価できる

労働、燃料、機械、資材などの投入量を独立して扱うため、ある資源の削減が他の資源の増加を伴う場合でも、その関係を明示できる。

### 7.3 自然資本の消耗による見かけ上の効率向上を区別できる

短期的な投入削減が土壌肥沃度などの消耗によって成立している場合、自然資本の維持条件によって、その生産体系を長期的に評価できる。

### 7.4 経営条件に応じた最適化が可能となる

労働力が不足する農場と土地が不足する農場では、優先的に削減すべき資源が異なる。本モデルでは、経営条件に応じた資源の利用可能量や制約を設定することで、それぞれの農場に適した生産体系を検討できる。

### 7.5 生産体系の比較に利用できる

例えば、慣行耕耘栽培と省耕起・地表有機物被覆栽培を比較する場合、収量だけでなく、労働、燃料、肥料、資材、土壌状態などを評価対象とすることができる。

これにより、単収の差だけでは把握できない資源利用上の特徴を明らかにできる。

## 8. モデルの限界と今後の課題

本稿で示した数式は、基本理念を数学的に表現した概念モデルであり、実際の農業経営に直ちに適用できる完成した計算モデルではない。

実用化に向けては、主に次の課題が存在する。

1. **投入資源の計測方法**：土地、労働、機械設備、資材などの投入量を、重複計上を避けながら定義する必要がある。
2. **必要生産量の設定**：必要とする生産量は、経営規模、販売計画、消費目的などによって異なる。
3. **経営成立条件の設定**：利益の定義、家族労働の評価、資本費用、資金繰りなどを整理する必要がある。
4. **自然資本の評価**：土壌養分、有機炭素、水資源などについて、適切な測定指標と維持条件を定める必要がある。
5. **時間的変動と不確実性**：気象変動、収量変動、資源価格の変動などを考慮する必要がある。
6. **複数の最適解からの選択**：パレート最適な生産体系が複数存在する場合、それらをどのように選択するかを検討する必要がある。
7. **実証的な妥当性検証**：実際の農業生産データを用いて、モデルの適用可能性と評価結果の妥当性を検証する必要がある。

また、投入資源を最小化することと、温室効果ガス排出量や生態系への影響を最小化することは必ずしも一致しない。これらを評価対象とする場合には、別途適切な環境制約や評価指標を設定する必要がある。

## 9. 結論

本稿では、農業生産を単位面積当たりの収量だけで評価することの限界を踏まえ、「必要な生産量を、持続可能な範囲で、最小限の資源投入によって確保する」という考え方を数理的に整理した。

その基本構造は、以下の三つの制約条件を満たしながら、複数の投入資源を最小化する多目的最適化問題として表現できる。

1. 必要な生産量を確保すること。
2. 農業経営として必要な利益を確保すること。
3. 長期的な生産能力を支える自然資本を維持すること。

このモデルでは、収量の最大化そのものを目的とせず、必要な生産水準を確保したうえで資源利用の最適化を目指す。

また、異なる資源を無理に単一の尺度へ統合せず、それぞれの投入量と相互関係を評価することを基本とする。

こうした考え方は、農業生産の効率を単収のみで判断するのではなく、資源制約、経営の継続性、自然資本の維持を含めて評価するための一つの枠組みとなり得る。

ただし、その有効性は、具体的な資源の定義、制約条件の設定、実際の生産データに基づく検証によって確認されなければならない。

本モデルは、農業生産の新たな評価尺度を確立するための出発点として位置づけられる。
