# 土壌と凍結・融解の関係：作用機構、土壌特性への影響および土地管理上の評価

**資料の性格：** 土壌科学に基づく一般的な解説・整理資料  
**対象：** 農地、草地、森林土壌などの季節的に凍結する土壌  
**作成日：** 2026年11月12日  
**文献・内容の最終確認日：** 2026年11月13日

## 要旨

土壌の凍結と融解は、熱・水分・土粒子・溶質・生物が相互に作用する過程である。土壌水が氷へ変化すると、体積膨張、未凍結部から凍結面への水分移動、氷層の成長、土壌粒子の変位などが生じる。融解時には水分と力学的支持状態が再編され、土壌の団粒構造、孔隙、透水性、侵食されやすさ、生物活動、炭素・窒素循環に影響する。

ただし、その効果は一定ではない。大きな土塊の破砕や孔隙の連結が有益に働く場合がある一方、耐水性団粒の崩壊、表面目詰まり、養分流亡、融解期の土壌侵食が進む場合もある。**土壌表面に霜が見られることだけでは、地中の凍結や土壌構造の変化を証明できない。** 土質、初期含水率、温度履歴、凍結深度、排水、積雪・地表被覆などを併せて評価する必要がある。

## 1. 基本概念と適用範囲

### 1.1 区別すべき現象

| 用語 | 主な仕組み | 土壌との関係 |
| --- | --- | --- |
| **霜（hoar frost）** | 大気中の水蒸気が冷えた地表や物体に氷として付着する | 表面現象。土壌内部の凍結を必ずしも伴わない |
| **土壌凍結（soil freezing）** | 土壌の孔隙水の一部が氷になる | 熱、水分、力学、化学・生物過程を変化させる |
| **霜柱（needle ice）** | 地中から供給される水が地表近くで柱状の氷として成長する | 表面粒子・幼苗の持ち上げや攪乱を起こす |
| **凍上（frost heave）** | 氷層の成長などにより地盤・土壌が隆起する | 根や地表物の変位、構造物への作用を生む |
| **融解（thawing）** | 氷が液体の水に戻る | 水分分布、強度、排水条件が変化する |
| **凍結融解サイクル（freeze–thaw cycle）** | 凍結と融解の一連の変化 | 繰り返しにより土壌構造等が累積的に変化し得る |
| **季節凍土** | 季節的に凍結し、暖候期に融解する土壌・地盤 | 農地や温帯・寒冷地の土壌管理に関係する |
| **永久凍土** | 少なくとも連続2年間、地温が0℃以下に保たれる地盤 | 気候変動・水文・地盤安定性の評価が重要 |

霜・霜柱の定義は気象庁の用語・観測資料に整合する[1]。降霜の観察と土壌凍結の観測は分けて扱う。

### 1.2 凍土は「完全に氷だけがある土壌」ではない

通常の土壌は固相（土粒子・有機物）、液相（水）、気相（空気）からなる。凍結すると一部の水が氷になるため、**土粒子・氷・未凍結水・空気**が共存し得る。微細孔隙や鉱物表面には氷点下でも未凍結水が残る。その量は温度、孔隙径、溶質濃度、鉱物組成によって変わる[2, 6]。

## 2. 凍結・融解を支配する条件

土壌凍結の強さは、気温だけでは決まらない。重要な変数は次のとおりである。

1. **土壌温度と時間：** 最低地温、氷点下継続時間、凍結・融解の速さ、繰り返し回数。
2. **水分条件：** 初期含水率、飽和度、地下水位、毛管水の供給、排水性。
3. **土性・鉱物：** 砂・シルト・粘土の割合、粘土鉱物、粒子間結合。
4. **初期構造：** 孔隙率、孔隙の連続性、団粒の耐水性、締固め、既存の亀裂。
5. **有機物・生物：** 根系、有機物による結合、微生物の活動、地表の残渣。
6. **地表境界条件：** 積雪、敷草・落葉、植生、日射、風、地形、地表面の水分。
7. **外力・土地利用：** 踏圧、車輪荷重、耕起、斜面条件、融解期の降雨・融雪。

とくに**氷層（アイスレンズ）の持続的な成長による凍上**は、低温だけでなく、凍上しやすい土質と凍結面への水の供給が重要となる[7]。一方、その場の孔隙水の凍結膨張による変形は、外部からの継続的な水供給がなくても起こり得る。

## 3. 物理的作用の機構

### 3.1 相変化と体積膨張

液体の水が氷になる際、同じ質量で比較すると体積は約9%増える。しかし、これは「土壌全体が9%膨らむ」という意味ではない。空気を含む孔隙に膨張分を収容できれば、土粒子に加わる変形は小さい。高含水率で膨張が拘束される場合には、土粒子や団粒へ応力が加わりやすい[3]。

また、凍結時には凝固潜熱が放出され、融解時には融解潜熱が吸収される。このため、土壌の温度変化は相変化に伴って緩和され、外気温と地温は同じようには変化しない。

### 3.2 凍結吸引と水分再分配

氷が成長する凍結面では水の化学ポテンシャルが低下し、周囲の未凍結土壌から液体水が移動することがある。この作用を**凍結吸引（cryosuction）**という。凍結面へ水が供給され続ければ、氷の成長量はその場の水の凍結膨張だけでは説明できないほど大きくなる[2, 6]。

結果として、凍結面付近への水分の集積、隣接する未凍結部の脱水、氷層の成長などが起こり得る。なお、内部の水分移動は必ずしも土壌全体の水分損失を意味しない。

### 3.3 アイスレンズ・凍上・霜柱

凍結面付近で氷が層状に集積すると、**アイスレンズ（ice lens）**が形成されることがある。氷層の成長が土壌を押し上げる現象が凍上である。地表付近では柱状氷の成長によって霜柱が形成され、表面土粒子や植物体を持ち上げる場合がある[7]。

凍上の程度は、水の供給、土質、凍結面の位置・移動速度、温度勾配などに依存する。シルト質・細粒分を含む土壌は一般に凍上を起こしやすいが、粘土含有量だけで一意には決まらない。

### 3.4 凍結に伴う脱水、亀裂、融解時の再配列

氷への水分集積によって周囲の未凍結部が脱水し、収縮や微細な亀裂を生じる場合がある。凍結中の氷は土粒子間を一時的に結合する一方、融解すると氷による支持が消失する。さらに、水が再流入することで土粒子が再配列し、土塊が崩壊することもある[2, 3]。

これは土壌内部の水分再分配による作用であり、水分が大気へ昇華して失われる**実際の乾燥・昇華損失**とは区別する。

## 4. 土壌物理性への影響

### 4.1 土塊と団粒

凍結融解は、大きな土塊を小さく分け、土壌を砕けやすくする場合がある。耕起後の土塊が冬季に細かくなる現象は、その一例である。一方、良好な**耐水性団粒**まで崩壊すると、細粒の分散や表面目詰まりにつながる。

重要なのは、**「土塊が小さくなること」と「安定した団粒構造が改善すること」は同義ではない**という点である。研究では、凍結融解後の団粒安定性について改善・悪化の両方が認められ、初期含水率、初期構造、有機物、土質に左右される[3, 5]。

### 4.2 孔隙と透水性

氷の成長・融解・土粒子の再配置により、孔隙の**総量だけでなく、径の分布と連続性**が変わる。これに伴い、通気性、浸透性、排水性、保水性が変化する[3, 4]。

- **凍結中：** 孔隙が氷に塞がれ、液体水の流動が制約されやすい。
- **融解後：** 連結孔隙が増えて浸透が改善する場合もあれば、細粒の分散・再沈積で目詰まりが進む場合もある。
- **表層だけ融解：** 下方に凍結層が残ると、水が滞留して表面流出・侵食が増える場合がある。
- **例外：** 凍土でも未凍結の大孔隙や優先流経路があれば水が浸透することがある。「凍土＝完全不透水」とは限らない[6]。

一例として、特定の土質・初期構造を用いた実験では、複数回の凍結融解後に連結孔隙が発達し、不飽和透水性の増加が報告された[3]。この増加率を一般の全圃場へ外挿することはできない。

### 4.3 硬さ、支持力、容積重

凍結中は氷の結合によって土壌の硬さ・支持力が高まることがある。融解直後は支持力が低下し、特に過湿状態では踏圧・車輪荷重による締固めや轍が生じやすくなる。容積重や孔隙率の長期的な変化は、凍上、沈下、排水、外力などの条件次第で増減する。

### 4.4 侵食、流出、土砂移動

融解直後の土壌は、団粒の不安定化、表面の軟化、下層凍結による浸透阻害が重なると、雨・融雪による侵食を受けやすい。斜面では表土の移動や土砂流出が重要な問題になる[2, 9]。裸地か被覆地かは、結果を左右する大きな要因である。

## 5. 土壌化学性と養分循環への影響

### 5.1 未凍結水の溶質濃縮

水が氷になる際、多くの溶質は氷から排除されやすく、残存する液体水に濃縮される。その結果、局所的なイオン強度・浸透圧・溶質の移動が変化し、鉱物の溶解・沈殿や粘土粒子の凝集・分散へ影響する場合がある[2]。ただし、軽微な表面霜で土壌全体のpHや肥沃度が大きく変化するとはいえない。

### 5.2 有機物と無機養分

団粒の破砕によって保護されていた有機物が露出したり、微生物・細根が損傷したりすると、溶存有機炭素・有機窒素や、アンモニウム・硝酸などの動態が変化する可能性がある[8]。融解時には可溶化、無機化、再固定、溶脱などが競合する。

**養分の可溶化は、土壌に新しい養分が加わることを意味しない。** 利用可能性が一時的に増す場合でも、流亡による損失が同時に増えることがある。

### 5.3 窒素・炭素・温室効果ガス

凍結融解の過程では、硝酸態窒素の溶脱、一酸化二窒素（N₂O）の放出、二酸化炭素（CO₂）放出、メタン（CH₄）の吸収・放出などが変化することがある。窒素循環に関するメタ分析では、アンモニウム態・硝酸態窒素、硝酸態窒素の溶脱、N₂O放出の増加が報告された一方、正味の窒素無機化速度や硝化速度については有意な変化が認められなかった[10]。**窒素の放出・損失と、無機化速度の増加を同一視しない**ことが重要である。実際の応答は土壌条件、気候、酸素状態、凍結の程度、観測期間によって異なる。

## 6. 土壌生物・植物への影響

### 6.1 微生物

低温、細胞外での氷形成、浸透圧変化は微生物にストレスを与える。微生物の一部は損傷・死滅するが、耐寒性や休眠、土壌微小環境による保護などにより生残するものも多い。融解後に温度と水分条件が整うと、微生物活動や有機物分解が再び高まることがある[8]。

したがって、「凍結によって土壌微生物が一斉に死滅する」「融解後に必ず肥沃度が上がる」のいずれも適切な一般化ではない。

### 6.2 土壌動物

ミミズ、線虫、節足動物などは、凍結深度、越冬形態、移動可能な深さ、被覆の有無に応じて異なる応答を示す。凍結融解による孔隙や表面構造の変化は、その後の生息環境にも影響し得る。

### 6.3 植物の根と苗

土壌中の液体水が減ると、根が吸水しにくくなり、凍結に伴う脱水ストレスが生じることがある。凍上・霜柱では根の引張り、切断、苗の持ち上げ・露出が問題となる。融解後の過湿は酸素不足を招くことがある。一方、融解後の土壌構造が適度に改善されれば、根の伸長環境が改善する可能性もある。

## 7. 土質・土地条件による影響の違い

| 条件 | 典型的な傾向 | 注意点 |
| --- | --- | --- |
| **砂質土** | 排水が良く、凍上は比較的小さいことが多い | 細粒分の混入や水供給があれば例外がある |
| **シルト質土** | 凍結面への水供給が成立すると凍上しやすい | 含水率・地下水位で大きく変わる |
| **粘土質土** | 水分保持・結合性が高く、亀裂や団粒変化が生じ得る | 粘土鉱物、透水性、初期構造の影響が大きい |
| **壌土** | 土塊破砕と団粒崩壊の両方があり得る | 「壌土なら改善する」とは限らない |
| **有機物の多い土** | 水分保持・団粒結合・断熱などが複合的に作用 | 水分量と被覆条件を分けて考える |
| **圧密・締固め土** | 氷による亀裂形成で構造が変わる場合がある | 深い締固めが必ず解消するわけではない[4] |
| **裸地** | 放射冷却、凍結、融解後の雨滴衝撃を受けやすい | 地形・気象条件によって異なる |
| **積雪・植物残渣で覆われた土** | 断熱作用により地温変動が緩和されることが多い | 被覆の厚さ・含水状態・形成時期で変わる[11] |

また、土壌の凍結深度と気温は一致しない。積雪が断熱層として働くことで、外気が低温でも地中の凍結が浅くなる場合がある。北海道の圃場実験でも、積雪操作による凍結深度・融雪水の浸透・流出の違いが確認されている[11]。

## 8. 時間経過に沿った土壌状態の変化

| 段階 | 主な作用 | 起こり得る状態 |
| --- | --- | --- |
| **冷却・降霜** | 表面の熱放出、霜の付着 | 表面だけ白くなり、地中は未凍結のままの場合もある |
| **土中の凍結開始** | 孔隙水の相変化、潜熱放出 | 氷による結合、液体水の減少 |
| **凍結の進行** | 凍結吸引、氷層成長、凍上 | 局所的な水分集積・脱水、亀裂・隆起 |
| **融解開始** | 氷の融解、支持力低下 | 過湿、沈下、表層の軟化 |
| **融解後の排水・乾燥** | 水分再分配、土粒子の再配列 | 孔隙・団粒の再編、土塊破砕・目詰まり |
| **複数サイクル後** | 作用の累積・初期構造の変化 | 改善、悪化、または小さな変化のいずれもあり得る |

## 9. 農地・草地・森林管理上の含意

### 9.1 「自然の耕耘」としての評価

凍結融解は、秋にできた大きな土塊の破砕や孔隙の連結に寄与することがあり、播種床づくりを助ける場合がある[3]。しかし、耕耘機による土壌の混合・反転とは作用範囲が異なる。深層の硬盤を必ず解消するわけではなく、団粒を壊す場合もある。したがって、**凍結融解を土壌改良の確実な代替技術として扱うべきではない**。

### 9.2 地表被覆とのトレードオフ

敷草、落葉、作物残渣、積雪などは地表の温度変動を緩和することが多く、霜柱・浅層凍結の発生条件を変える。その一方、雨滴衝撃の緩和、侵食抑制、有機物供給、水分保持といった効果がある。

「凍結融解で土塊を細かくするために裸地を維持すべきか」という判断は、表面侵食、土壌構造、作物、地域の気象を含めた総合評価が必要である。凍結の有無だけで被覆管理の優劣は決められない。

### 9.3 実務上の留意点

- **融解直後の過湿土壌への進入を避ける。** 支持力低下時の車輪荷重・踏圧は、締固めや轍を残し得る。
- **斜面・裸地では融雪・降雨時の侵食を重視する。** 表層融解と下層凍結が重なると水が流出しやすい。
- **幼苗・浅根性植物では凍上・霜柱を確認する。** 被覆、播種時期、苗の定着が重要になる。
- **凍結による養分供給を施肥の代わりと見なさない。** 可溶化と流亡を区別する。
- **冬季の変化を評価するときは、土壌を繰り返し掘り返す調査自体の攪乱にも注意する。**

## 10. 現地調査・比較試験の方法

### 10.1 最低限記録したい項目

| 指標 | 観察・測定の例 | 明らかになること |
| --- | --- | --- |
| 気温・地温 | 地表、深さ5・10・20 cmの温度を記録 | 凍結の可能性・時間帯・深度の推定（温度だけで氷の存在は確定できない） |
| 凍結深度 | 凍結深度計、必要に応じて温度・水分・氷の観測を組み合わせる | 凍結面の位置と変化（温度だけの推定には限界がある） |
| 土壌水分 | 同じ深さ・位置で経時比較 | 凍結前後の水分状態 |
| 表面状態 | 定点写真、霜柱・隆起の有無 | 地表変形と融解後変化 |
| 土塊径 | 一定面積・条件で粒径別の比較 | 土塊の破砕 |
| 団粒の耐水性 | 可能なら湿式ふるい分け等 | 安定した団粒が維持されたか |
| 土壌硬度・容積重 | 同じ含水状態を意識して測定 | 締まりの変化 |
| 浸透性 | 簡易浸透試験等 | 孔隙・水の通り道の変化 |
| 表面流出・侵食 | 雨・融雪後の土砂移動の記録 | 管理上の不利益 |
| 土壌分析 | 必要に応じて無機態窒素、DOC等 | 養分循環の変化 |

### 10.2 比較の設計

裸地と被覆地、圧密の強い場所と弱い場所などを比較する場合は、土性、斜面、初期水分、日射、植生、土壌管理履歴の差をできるだけ揃える。**降霜前、凍結中、融解直後、排水・乾燥後**を分けて記録し、複数地点・複数日で反復する。

同じ圃場でも「融解直後の柔らかさ」と「乾燥後の団粒の安定性」は異なる指標である。触感だけで構造改善と判定しない。

## 11. 総合整理と判断上の注意

土壌の凍結・融解は、次のような連鎖として理解できる。

**冷却 → 土壌水の凍結・水分移動 → 氷の成長と応力発生 → 孔隙・団粒の変形 → 融解と排水 → 土壌物理性・養分循環・生物活動の再編**

ただし、この連鎖がすべての土壌で同じ強さ・同じ順序で生じるわけではない。表面に霜が付着しても、土壌内部の凍結が起きなければ変化はごく小さいことがある。

評価に当たっては、以下を区別する必要がある。

1. **表面霜の観察と、土壌内部の凍結の確認。**
2. **単なる土塊の破砕と、耐水性団粒の改善。**
3. **融解直後の一時的な軟化と、長期的な土壌構造の改善。**
4. **養分の可溶化と、土壌全体の養分供給量の増加。**
5. **実験室での強い凍結融解処理と、実際の圃場での浅い・短時間の凍結。**

結論として、凍結融解は土壌形成と季節的な構造変化に関与する重要な自然過程である。その影響を**有益・有害の一方に決めつけず、土壌物理性・化学性・生物性と土地管理の目的に照らして評価する**ことが適切である。

## 12. 用語集

- **団粒：** 土粒子や有機物が結合してできる比較的安定した集合体。
- **耐水性団粒：** 水に浸されても崩れにくい団粒。
- **孔隙：** 土粒子間にある、水や空気の入る隙間。
- **不飽和透水性：** 孔隙の一部が空気で満たされる土壌における水の通りやすさ。
- **凍結吸引：** 凍結面へ向けて未凍結水が移動する駆動作用。
- **アイスレンズ：** 地中に形成される層状の氷の集積。
- **凍上：** 凍結に伴い土壌・地盤が持ち上がる現象。
- **未凍結水：** 氷点下でも液体として残る土壌水。
- **溶脱：** 溶けた養分などが水に伴って下方へ移動・流出すること。
- **目詰まり（表面封鎖）：** 微細粒子の移動などで土壌表面の透水性が低下すること。
